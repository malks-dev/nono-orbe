# 03 — Da ideia à primeira interface

Com o ambiente organizado, comecei a transformar a ideia do Nono Orbe em uma interface.

Utilizando **vibe coding**, descrevi o que imaginava para a página inicial e gerei uma primeira versão funcional.

Ela já reunia os principais acessos em categorias, mas ainda parecia um painel genérico. Funcionava como ponto de partida, porém faltava uma identidade visual que representasse melhor a proposta do projeto.

![[03.0-codigo-v1.png]]

## Buscando referências

Antes de continuar escrevendo código, pesquisei referências visuais no Pinterest.

Procurei interfaces escuras, painéis modulares, sistemas de navegação, bibliotecas digitais e campos de pesquisa integrados com inteligência artificial.

A intenção não era copiar uma interface pronta, mas entender quais elementos poderiam ajudar a construir a personalidade do Nono Orbe.

![[03.0-referencias.png]]

## Criando uma direção visual

Com essas referências, montei no Photoshop uma proposta mais próxima do que eu imaginava para o projeto.

Essa etapa ajudou a definir melhor a hierarquia das informações, o espaço de pesquisa, as categorias, os atalhos e a atmosfera visual da página.

O Photoshop se tornou uma ponte entre a ideia e o código: um lugar para testar decisões antes de pedir uma nova implementação.

![[03.1-photoshop-v1.png]]

## Uma nova entrega

Com a referência visual pronta, voltei ao vibe coding com instruções mais claras.

A nova versão não surgiu apenas de um pedido genérico. Ela foi construída a partir de pesquisa, comparação, direção visual e ajustes na forma de comunicar a ideia para a inteligência artificial.

O resultado ficou mais próximo da identidade que eu queria para o Nono Orbe.

![[03.2-codigo-v2.png]]

O vibe coding acelerou a construção, mas não substituiu o processo criativo.

A inteligência artificial ajudou a transformar instruções em código. As referências, as escolhas visuais e a direção do projeto continuaram sendo humanas.
