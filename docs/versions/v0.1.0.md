# Nono Orbe v0.1.0 — Primeiro contêiner

Data: 27 de agosto de 2026  
Estado: implementado e pronto para validação no servidor

## Objetivo

Criar a menor unidade executável do Nono Orbe: uma aplicação PHP exibindo “Hello, World!” em um contêiner Docker acessível pela porta `9000`.

## Decisões

- A imagem-base é `php:8.3-apache`.
- O Apache escuta na porta `80` dentro do contêiner.
- O Docker publica o serviço em `127.0.0.1:9000` por padrão.
- A restrição a `127.0.0.1` evita exposição direta e permite que o Cloudflared seja a camada pública.
- O diretório `public/` é montado como somente leitura durante o desenvolvimento inicial.
- O nome do projeto Docker é `nono-orbe`.

## Como validar

```bash
docker compose config
docker compose up -d --build
curl --fail http://localhost:9000
docker compose ps
```

Resultado esperado:

- o serviço `web` aparece como saudável;
- a resposta HTTP contém `Hello, World!`;
- a página identifica a versão `0.1.0`.
