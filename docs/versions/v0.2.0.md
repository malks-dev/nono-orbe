# Nono Orbe v0.2.0 — Fundação do Core

Data de início: 28 de agosto de 2026
Estado: em desenvolvimento
Última versão lançada: `0.1.0`

## Objetivo

Estabelecer a fundação técnica do Nono Orbe Core e preparar a aplicação para utilizar dados persistentes em ambientes Local e WebFarm.

A versão `0.2.0` não está lançada. Este documento acompanha sua preparação.

## Escopo

A versão reúne quatro fundamentos:

1. estrutura reutilizável do Core;
2. banco MySQL compatível com WebFarm;
3. configuração central e conexão da aplicação;
4. verificação de saúde da aplicação e do banco.

## Implementado

### Core

* Estrutura inicial em `core/`.
* Separação entre configuração, banco, domínio, suporte e apresentação.
* Documentação das responsabilidades do Core.
* Preparação para distribuições Local e WebFarm.

### Contrato de identidade

* Contrato `webfarm-core-identity/1.0`.
* Identidade compartilhada por UUID.
* Separação entre autenticação e personalização.
* Definição do primeiro usuário local como administrador de um cliente pessoal.
* Proibição de exportar hashes de senha, tokens e sessões.

### Banco

* MySQL 8.4.
* Banco lógico `webfarm_orbe`.
* Controle por `schema_migrations`.
* 11 migrations.
* 18 tabelas.
* Política de seeds sem usuários ou dados pessoais.

### Experiência personalizada

* Perfis.
* Preferências por contexto.
* Categorias.
* Atalhos.
* Exclusão lógica.
* UUID da instalação de origem.
* Controle de versão dos registros sincronizáveis.

### Comunicação

* Conversas.
* Participantes.
* Mensagens.
* Respostas entre mensagens.
* Metadados de arquivos.
* Anexos.

### Recursos e atendimento

* Recursos locais, WebFarm e externos.
* Vínculos entre recursos e projetos.
* Solicitações de ajuda ou serviço.
* Histórico de eventos das solicitações.

### Portabilidade

* Registros de exportação.
* Registros de importação.
* Manifesto e checksum.
* Detecção de conflitos.
* Preparação para o formato `orbe-avatar`.

### Docker

* Serviço MySQL adicionado ao Compose.
* Imagem `mysql:8.4`.
* Driver PDO MySQL adicionado ao PHP 8.3.
* Isolamento por `ORBE_PROJECT_SLUG`.
* MySQL publicado somente em `127.0.0.1`.
* Serviço web aguardando o healthcheck do banco.

### Segurança

* `.env` fora do Git.
* Storage fora do Git.
* Senhas distintas para root e aplicação.
* Migrations sem dados pessoais.
* Seeds iniciais vazios.
* Proteção para dumps, backups, exportações e chaves privadas.

## Critérios para lançamento

A versão `0.2.0` poderá ser lançada quando:

* a aplicação carregar configuração central;
* o PDO conectar ao MySQL;
* `/health` validar aplicação e banco;
* erros não exibirem dados sensíveis;
* todas as migrations permanecerem aprovadas em banco vazio;
* a documentação refletir os comandos reais;
* o teste local passar após um clone novo;
* a versão exibida pela aplicação for atualizada;
* o changelog transformar `[Não lançado]` em `[0.2.0]`.
